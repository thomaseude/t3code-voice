# X / Bluesky, in English

1/ I drive my coding agents by voice now, iPhone locked in my pocket 🎧
"Start Claude on my-shop to fix the checkout tests."
…and it tells me when it's done.
Open source, unofficial companion for T3 Code 👇 [video]

2/ The phone only carries audio (WebRTC). A small Node service next to the server talks
to T3 on loopback. Face ID on every start, one-time QR pairing, no keys on the phone.

3/ Voice runs on your ChatGPT plan through Codex, with the OpenAI API as a fallback and a
daily budget.

4/ MIT, TypeScript + SwiftUI, good first issues open:
https://github.com/thomaseude/t3code-voice

# Launch kit

Drafts for making T3 Voice known, and the order to post them in. Thomas posts each one
from his own accounts and answers the comments himself: the communities below expect the
author, not a bot, and Hacker News asks for no AI-generated posts or comments.

**Rewrite each draft in your own words before you post it.** The drafts give the facts and
the structure. Readers spot generated text, and it costs trust.

## The message

One sentence, the same everywhere: **"Go for a run. Your coding agents keep working, and
you manage them by voice."**

- Open every post with the scene (out running, AirPods in, phone locked), not with the
  architecture. The technical part comes second, for those who keep reading.
- The idea behind it: with agents, the job is to give direction, wait and check. Giving
  direction does not need a screen.
- Running is the image. Walking the dog, cooking and driving are the same promise.

## Before any post

- [ ] PR #61 merged (README, CONTRIBUTING, templates).
- [ ] A 30–60 s demo video, **filmed outdoors while you run** (a friend films, or a chest
      strap): the phone stays in the pocket, you start a task by voice, you hear the
      "finished" announcement. A screen recording at a desk does not show the idea. Add
      it to the README.
- [ ] Turn on the subtitles in the video (the assistant speaks French).
- [ ] Two hours free after each post to answer the comments.

## Rules

- **Always write "unofficial".** T3 Code's README requires that projects using the T3 name
  make it unmistakable that they are not official.
- **No posts in other projects' issues or pull requests.** The T3 Code repository closes
  feature requests and asks contributors to stay away; a promotion there would be spam.
  Its Discussions have no "show and tell" category, so use the Discord instead.
- **No vote requests.** Hacker News penalises posts whose link was shared with "please
  upvote". Share the link only after the post is live, and only to say "it's up, feedback
  welcome".
- **One subreddit per day**, each with its own text, and read each subreddit's rules
  first (some allow self-promotion only on a given day).
- **Answer every comment**, especially the critical ones, with facts.

## What to measure

Stars, but mostly: Discussions opened, issues commented "I'll take this", forks with a
branch. A contributor usually comes after using the tool, so the first goal is users.
